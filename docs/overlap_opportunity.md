# Overlap opportunity diagnostic

The available EMN001 archive contains renamed FASTQ reads, references and
assemblies, but its manifest does not include the rename mapping generated by
the upstream workflow. No per-read origin table was found. Therefore this
diagnostic uses **reference mappings as a proxy, not simulation truth**.

`experiments/overlap_opportunity.py` takes query-name grouped SAM/BAM through
pysam, requires unique query names and bounds input to 100,000 query groups by
default. Only single MAPQ >=30 (excluding unknown 255), full-length ungapped
alignments without reported alternative/split mappings are eligible. SAM SEQ
and QUAL already follow alignment orientation. All intervals are 0-based,
half-open. Unmapped, ambiguous, low-quality and clipped/gapped reads are counted
separately rather than assigned speculative origins.

`--read-names-fastq FASTQ[.gz]` restricts the streaming BAM scan to the exact
query names in a frozen cohort. The loader retains names only, validates complete
four-line records, equal sequence/quality lengths and unique nonempty names, and
fails if any requested name is absent from the alignment file. The summary reports
source, requested and matched query-group counts so a silent join loss cannot be
mistaken for low coverage.

`coverage.tsv` reports each reference's covered union, eligible aligned bases,
mean depth over its full length, and components connected by >=30-base overlaps.
Components are an optimistic connectivity description of eligible mappings,
not attainable contigs or a biological upper bound. Excluded reads may connect
components. Identical intervals contribute depth but not additional covered
sequence. Molecule provenance is unavailable here: distinct query names are
treated as distinct molecules, matching the current single-input path.

For up to 2,000 seeded-random eligible targets, the script enumerates expected
same-reference dovetails and traces the existing candidate finder at k15, eight
anchors, occurrence cap100, one anchor match, overlap30, DNA .9, RY .99, rescue
off. `overlaps.tsv` gives the first failure or selection at each expected offset.
The candidate index contains eligible reads only, so occurrence-cap effects are
not identical to the full assembly. Opposite directions of a pair and targets
from the same locus are correlated; do not treat them as independent trials.
Other selected dovetails are counted as outside the proxy, not proven false.

Interpret `summary.json` in order: eligible fraction, per-reference opportunity,
then candidate-stage loss. This does not measure clustering, ownership or final
extension acceptance. If the eligible subset is too small or unrepresentative,
obtain origin mappings or use a known-truth synthetic benchmark; do not tune
assembly thresholds from an ambiguous mapping subset.

This benchmark changes no assembler behavior. Synthetic unit tests exercise
overlap thresholds, covered unions, mapping filters, and both SAM orientations.
